Сознательно не используем

Отвергнуто в журнале решений, в CLAUDE.md или в плане RUN.md — источник указан в конце строки. Без новых фактов не предлагается заново.

  • Kubernetes, Kafka, очередиMVP — только управляемые сервисы GCP; платформа MathTrail — при росте нагрузки. R01
  • Firestore вместо PostgresСтек выбран осознанно, данные и хранилище OpenFGA — в Neon. R08
  • OpenFGA отдельным сервисомСайдкар на localhost: нет сетевого прыжка и отдельного холодного старта. R09
  • WebSocket через rewrites HostingПоддержка не заявлена — у Centrifugo свой адрес Cloud Run. R10
  • canvas.v1 из contractsПиксели, нет времени у точек, семантика Kafka — свой пакет canvasapi.v1. R12
  • Отдельный репозиторий ui-webAPI и клиент меняются одним pull request. R13
  • golang-jwt + keyfunc для ID tokenAdmin SDK всё равно нужен для удаления аккаунта и сам кеширует ключи. R14
  • Mathpix и движок проверки шаговКаждому следующему предмету понадобился бы свой движок; верность ответа решает ключ. R37
  • Модель сама решает, верен ли ответОна могла бы назвать верный ответ неверным, и ключ бы этого не поймал. R37, R38
  • Черновик на сервереШтрихи остаются на устройстве, на проверку уходят две картинки, и сервер их не хранит. R42
  • Gemini 2.5 FlashСнимается 16.10.2026; модели — с точным ID через eval-набор. R22
  • Горутина после ответа, Cloud TasksCloud Run почти не даёт CPU после ответа; всё внутри запроса. R23
  • k6, Locust, GatlingПротокол API и protobuf пришлось бы вести на втором языке; инструмент — на Go. RUN.md, черновик разбиения E2
  • DI-фреймворкРучной контейнер app.NewContainer, как в mentor-api. CLAUDE.md, Wiring
