## Что нашёл прогон

1. **Новый аккаунт не может войти сразу.**
   - Задание входит аккаунтом, привязку которого apply этой же выкладки создал секундами раньше.
   - Исправлено в T12: задания `deploy` и `hosting` после входа ждут, пока аккаунт даст токен — `just ci-identity-ready`, до 8 минут.
   - Без нового аккаунта ожидание занимает одну попытку.
2. **Sink `_Default` менялся в каждом плане.**
   - Конфигурация просила `unique_writer_identity = false`. Провайдер 8.3.0 читает sink без идентичности как sink с уникальной и показывал `true → false` в каждом плане и apply.
   - У sink, чей бакет в его же проекте, идентичности не бывает (справочник Cloud Logging API, прочитан 2026-10-14).
   - Теперь в конфигурации `true`, и тест держит это значение.
3. **Адрес сервиса.**
   - Выход `service_url` давал адрес со случайной частью (`…-uk.a.run.app`), а R55 и документы называют адрес по номеру проекта.
   - Теперь выход — адрес по номеру проекта, из атрибута `urls`; тест на это есть.
   - По нему же идут smoke выкладки и ссылка окружения `prod`.
